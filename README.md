A full stack todo app with authentaction 

In this todo app you will crate a todo update it and delete it also can't access another todo for saftey purpose 

First you need to login in the app then you access the all feature of this app 

Technology used- 
  Python – Backend programming language.

  FastAPI – Building RESTful APIs.

  SQLAlchemy – Database ORM.

  Pydantic – Data validation.

  MySQL – Relational database.

  Uvicorn – ASGI server.

Frontend

HTML – Structuring the user interface.

CSS – Styling the application.

JavaScript – Frontend and API communication (if implemented).

The main objective of this project is to gain practical experience in full-stack development,
REST API development, database integration, CRUD operations, and frontend-backend communication.
